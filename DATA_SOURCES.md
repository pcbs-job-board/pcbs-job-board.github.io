# Data sources

The parts list in `data/parts/` was compiled from community resources. Thank you to their authors.

| Source | Used for |
|---|---|
| "PCBS1 Parts & Unlock Levels v1.15.3.0.1 – Base Game Parts" workbook (community, OneDrive) | All categories: names, unlock levels, prices, platform lock, DLC flag |
| [PC Building Simulator HTML Calculator](https://jacobwklein.github.io/PC-Building-Simulator/HTML-Calculator/Current-Version/PC-Building-Simulator-HTML-Calculator.html) by jacobwklein | Cross-check of CPU/GPU/board/RAM/storage/case data |
| [PC Building Simulator Wiki – All Components](https://pcbuildingsim.fandom.com/wiki/All_Components) (CC BY-SA) | Cross-check of PSU, cooler, fan and cable names |
| Missing-part reports from users (GitHub issues labelled `missing-part`) | Additions, marked `source = report #N` in the CSVs |
